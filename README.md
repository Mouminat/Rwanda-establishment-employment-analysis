## Project Description
This project focuses on analyzing the distribution of business establishments and employment across Rwanda using data from the Rwanda Establishment Census 2023.

The project will use an Oracle database to organize establishment information and generate useful reports based on location, economic activity, establishment size and employment.

## Problem Statement
Understanding how businesses are distributed across Rwanda and how many people they employ is important for economic analysis. This project aims to organize the available establishment census data to make this information easier to retrieve, compare and analyze.

## Objectives
- Design a relational database using Oracle.
- Organize establishment information by district and economic activity.
- Analyze establishment sizes and employment information.
- Develop PL/SQL procedures, functions and other database operations.
- Create an interactive analytical dashboard.

## Data Source
