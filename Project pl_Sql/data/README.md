
# Dataset Documentation

## Data Source
National Institute of Statistics of Rwanda (NISR).

Dataset: Rwanda Establishment Census 2023.

https://microdatabk.statistics.gov.rw/catalog/112

## Purpose
This folder will contain documentation about the dataset, selected variables, data preparation and data cleaning.

## Data Preparation
The dataset will be inspected before selecting the records and variables required for the project.

The final selection method and data-cleaning steps will be documented here.

## Privacy and Access
Only data permitted for educational use will be used. Restricted or personally identifiable information will not be uploaded to GitHub.
