
# SQL and PL/SQL Scripts

This folder will contain the SQL and PL/SQL code developed for the project.

Planned scripts include:

- Database table creation.
- Primary key and foreign key constraints.
- Data insertion and loading.
- Stored procedures.
- Functions.
- Cursors.
- Exception handling.
- Triggers and auditing.
- SQL queries and reports.

The scripts will be added during the database development phases.
