
# Project Innovation

## Innovation Type
Analytical Dashboard.

## Description
The project will include an interactive dashboard connected to the Oracle database.

The dashboard will help users explore establishment distribution and employment information across Rwanda.

## Planned Features
- View establishment distribution by district.
- Compare economic activities.
- Examine establishment sizes.
- View employment summaries.

## Implementation
The dashboard technology will be selected during development.

Instructions for installation, database connection and usage will be documented here.
